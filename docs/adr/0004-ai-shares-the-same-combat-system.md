# AI Opponent uses the identical combat system, with direct-state perception

The AI Opponent doesn't select from a library of canned attack animations. It drives its own Target Point through the same physics-chased Reach Sphere system the player uses (see ADR-0001), just generated by its GameplayStateTree instead of mouse input. To react, it reads the player's live Target Point angle and angular velocity directly, rather than through any simulated vision/perception system.

Both choices trade implementation simplicity for fairness: a finite AI move-set would let the player learn and exploit its gaps in a way the AI itself can't do back, and a duel has no fog-of-war or line-of-sight question to justify a perception layer — both Combatants are always looking at each other by definition.
